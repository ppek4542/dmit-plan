## 线路怎么选：Premium 和 Lite 的实际区别

这个问题我被问过好几次，简单说：

**Premium 系列**走的是 CN2 GIA 线路，三网回程都走这条路，晚高峰表现稳定。价格贵，但贵在线路质量上。如果你对延迟敏感，或者主要在国内访问，Premium 是值得的。

**Lite / Eyeball 系列**价格低一截，线路走普通优化，白天用没什么差别，晚高峰偶尔会有波动。预算有限、对稳定性要求没那么极端的话，Lite 够用。

香港和日本节点的延迟天然比洛杉矶低，但流量配额也小很多，价格也更高。我自己测过，香港节点到国内的延迟大概在 30ms 以内，东京稍高一点，洛杉矶 Premium 大概在 150ms 左右。

首先确认你访问的是 `dmit.io` 这个域名。如果确实无法访问，可能是本地网络问题，换个网络环境或者用代理访问官网本身。官网没有国内镜像，也没有备用域名。

不能。DMIT 部分热门套餐库存有限，Sold Out 就是真的没货了。可以隔一段时间再来看，或者选同系列其他配置。

### 买了之后多久能用？

付款完成后系统自动开通，一般几分钟内就能收到 VPS 的 IP 和登录信息邮件。不需要人工审核。

### DMIT 有没有优惠码？

官网偶尔会在特定节日推出促销，具体折扣码以官网公告为准。没有长期通用码，网上流传的大部分已经过期。
